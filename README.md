# Compiler Design Project

The project takes a custom Intermediate Representation (IR) program, converts it into bytecode, and executes the bytecode using a stack-based Virtual Machine (VM).

## Project Flow

IR Program
    ↓
IR Processing
    ↓
Basic Blocks and CFG
    ↓
Bytecode Generation
    ↓
Virtual Machine
    ↓
Program Output

## Main Components

### main.py
The main entry point of the project. It controls the overall compilation and execution process.

### ir.py
Handles the Intermediate Representation (IR) and creates basic blocks and the Control Flow Graph (CFG).

### codegen.py
Converts IR instructions into bytecode instructions that can be executed by the VM.

### isa.py
Defines the instruction set used by the virtual machine, such as LOAD, STORE, ADD, JMP, CALL and RET.

### vm.py
Implements the stack-based Virtual Machine that executes the generated bytecode.

### tests.py
Contains tests used to check whether the different components of the project work correctly.

### examples/
Contains sample IR programs used for testing and demonstrating the compiler.

## Features

- Custom Intermediate Representation
- Basic Block generation
- Control Flow Graph (CFG)
- Bytecode generation
- Stack-based Virtual Machine
- Function calls and returns
- Conditional and unconditional jumps
- Arithmetic and comparison operations
- Bytecode disassembly
- VM execution tracing

## Running the Project

Make sure Python 3 is installed.

Run an IR program:

    python3 main.py examples/sum.ir

Display the Control Flow Graph:

    python3 main.py examples/sum.ir --cfg

Display generated bytecode:

    python3 main.py examples/sum.ir --dis

Display VM execution trace:

    python3 main.py examples/sum.ir --trace

## Example

For the `sum.ir` example, the program calculates:

    1 + 2 + 3 + ... + 10

Output:

    55
